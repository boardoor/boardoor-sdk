# Changelog

## 0.1.0-alpha.1 (release candidate)

- Core: make the development debug-panel toggle text readable in light themes by
  pairing its dark background with explicit light text.
- UI: declare and test the exact alpha.1 core tuple. No UI API changes.

Upgrade both packages together from alpha.0. No application code or game-rule
migration is required. This release remains an alpha and does not change the
supported public API or stable-promotion requirements.

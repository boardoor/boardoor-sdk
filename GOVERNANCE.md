# Governance

Boardoor maintainers steward the repository, review contributions, define supported public
surfaces, and authorize releases. The `@boardoor/maintainers` GitHub team is the intended code
owner for workflows, repository policy, security, release, compatibility, and package surfaces.

Contributions are accepted through pull requests subject to CI, DCO 1.1, review, provenance, and
repository rules. Submitting or using a package does not grant merge, release, npm, deployment, or
production authority. Maintainer or release authority is granted only through an explicit future
governance decision.

Changes to governance, licensing, protected repository surfaces, release authority, supported
API, or compatibility policy require maintainer review. Routine bypass of required rules is not
part of this model.

This document is a local template. Team membership, repository rules, DCO installation, and
authority promotion require separate live verification and are not established by this file.

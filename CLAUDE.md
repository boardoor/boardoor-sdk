# CLAUDE.md

Follow `AGENTS.md` in this repository. This is an independent public SDK
repository, not a child package of a private monorepo.

For commits, inspect the repository-local status and diff, then use
`git commit --signoff`. Do not let `/commit-commands:commit` or another generic
command create an unsigned commit. Do not seek private Boardoor context or use
another checkout as a dependency source.
